# AIと作った中学歴史の学習ゲーム「ドパ・日本史」の作り方

中学社会の歴史（安土桃山時代〜日露戦争）を、5問ずつテンポよく遊べる無料の学習ゲーム「ドパ・日本史」を作りました。スマホのブラウザで開くだけで遊べて、登録はいりません。

▶ 遊ぶ：https://twosee-apps.github.io/rekishi-dopa-app/

## どんなゲームか

- 5つの時代、全216問。1周5問なので、すき間時間に遊べます
- 正解を重ねるほど画面が盛り上がり、いちばん上の段階が「祭り」です
- マスコットの「ハッピー」は、正解の数ではなく遊んだ回数で7段階に進化します
- 史料・表・略地図を読む問題もあります
- 難易度は「かんたん・ふつう・むずかしい」の3つ
- 一度開けば、電波がなくても遊べます。記録はお使いの端末の中だけに残り、外部には送信されません

## 作り方（人とAIの分担）

- 人：何を作るか、何を大事にするかを決める。遊んでみて、直す所を出す
- AI：プログラム作り・テスト・確認・文章の推敲

実装は Claude（Anthropic）に依頼文を送って任せ、その結果を確認を担当するAI（同じく Claude）が確かめてから公開する、という流れで26回の改良を重ねました。最初の公開までは約1日、そこから1週間ほどで今の形になっています。

## 品質のために続けたこと

- 問題の年号や人名は、公的機関などの公開資料と照らし合わせて確認（学習の際は、念のため教科書でもご確認ください）
- 解説は60字以内。覚えたことをテストに書いても誤りにならない範囲で言い切る
- 作ったAIとは別の会社のAI（OpenAI の Codex）にも、まちがいや抜けがないか確認させる
- 自動テストを毎回実施（単体テスト103件、スマホの画面幅での通しプレイ28項目）
- 実際に遊んでもらった感想から「1周20問を5問に」短くするなど、遊んだ人の声で直す
- 画面の文章は Gemini（Google）で推敲

## 使っている技術

HTML・CSS・JavaScript だけで作り、外部のサービスや広告は入れていません。公開は GitHub Pages（無料）。電波がなくても遊べるのは、ブラウザの Service Worker（オフラインでも動かせる仕組み）のおかげです。

自分で遊ぶこと、学校の授業やご家庭で使うこと、URL や QR コードを配って紹介することは自由です。
